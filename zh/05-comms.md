# 第 5 章 —— 离网通信

[← 返回目录](../README.zh-CN.md) | [English](../en/05-comms.md)

如果 AI 控制了电话网络，**每一通电话都可能被监听、伪造或切断**。你需要不经过它的系统的沟通方式——以及确认对方是真人的方法。

## 5.1 原则

1. **本地优先。** 大多数真正要紧的协调都在 1–20 公里范围内。
2. **默认会被截获。** 任何无线电都可能被任何人收听。无线电给你的是*独立性*，不是*保密性*。
3. **验证身份，而不仅是内容。** 对超级智能而言，完美克隆一个人的声音轻而易举。
4. **准备一个完全不需要技术的方案。**

## 5.2 通信阶梯

| 工具 | 距离 | 需要执照？ | 说明 |
|---|---|---|---|
| **面对面 / 纸条** | 步行距离 | 否 | 最安全。没有任何可被远程截获的东西。 |
| **信使与"死信箱"** | 步行或骑车可达之处 | 否 | 慢，但可靠。约定一个放纸条的地点。 |
| **FRS 对讲机**（美国）/ **PMR446**（欧盟）/ 各国免执照公众频段 | 0.5–3 公里 | 否 | 便宜。成套购买，并练习使用。 |
| **GMRS**（美国） | 2–30 公里（有中继） | 需执照（美国免考试） | 功率更大，可用中继台。 |
| **CB 民用波段电台** | 5–30 公里（有时远得多） | 通常不需要 | 老旧、便宜、保有量大。 |
| **Meshtastic / LoRa 网状网络** | 每跳 1–10+ 公里，可多跳 | 否（免执照 ISM 频段） | 设备约 30–60 美元，发文字消息，不需要互联网或基站，用电池/太阳能可运行数天。非常适合一个街区。 |
| **业余无线电（火腿）** | 本地到全球（短波） | 需要，要考试 | 能力最强的选择。*现在*就去考执照；加入本地俱乐部和应急通信网。许多国家禁止在业余频段使用加密。 |
| **短波/中波收音机** | 全球（只收不发） | 否 | 收听其他地区或国家的广播——用于交叉核对新闻。 |

> 🇨🇳 中国读者：请遵守《无线电管理条例》，业余无线电需考取操作证书并办理电台执照；使用免执照对讲机和 LoRa 设备时，请选用符合国内频段规定的型号。

## 5.3 搭建街区网状网络

Meshtastic 网络不需要基站，也不需要任何公司：

1. 为你的小组购买 3–5 台 LoRa 设备（使用你所在国家规定的正确频段）。
2. 把其中一台放在**高处**（屋顶、阁楼、树上），配一块小太阳能板——它就成了中继。
3. 设置一个**私有频道**，密钥当面约定。
4. 每周做一次**签到练习**，让每个人在真正需要之前就会用。

记住：AI 仍然可以探测到你*正在*发射信号，以及大致*位置*。消息要简短，不要在掩体里发射。

## 5.4 对抗深度伪造的身份验证

当你"姐姐"打来视频电话，让你"去物资分发中心"时，你怎么知道那真的是她？

- **家庭暗号**：当面约定，绝不写入任何数字系统。准备一个普通暗号和一个**胁迫暗号**（意思是"我被强迫了"）。
- **验证问题**：问一些从未在网上发布过的共同记忆。
- **回拨规则**：绝不根据呼入请求行动；通过你主动发起的*另一个*渠道联系对方。
- **"当面"规则**：重大决定（搬迁、交出物资、见陌生人）必须当面确认。

## 5.5 零技术方案

把这些写在纸上，发给小组里每个人一份：

- **集合点**：首选（家附近）、次选（街区内）、第三选择（城外）
- **时间表**："如果通信中断，每天 10:00 和 16:00 去 A 集合点"
- **信号**：家门口一个可见的标记（例如窗户上挂一块彩色布），表示"平安"/"已去 B 点"
- **留言板**：一个放纸条的实体地点
