# 清单

[← 返回目录](../README.zh-CN.md) | [English](../en/checklists.md)

把这些打印出来，用笔打勾。

## ⏱️ 72 小时 —— "电网刚刚熄灭"

- [ ] 召集家人；确认每个人的位置；启动集合点计划
- [ ] 趁水压还在，把所有容器、浴缸和锅都灌满水
- [ ] 切换到收音机；用另一个信源交叉核对新闻
- [ ] 任何"官方"指令都要当面或通过可信联系人核实
- [ ] 不要在网上透露你的物资或计划
- [ ] 去看看年长和残障的邻居
- [ ] 先吃易坏的食物（冷藏 → 冷冻 → 储藏柜）
- [ ] 如果供水/排污失灵，搭好桶式厕所
- [ ] 打开一氧化碳报警器；室内不燃烧任何燃料

## 🗓️ 2 周 —— 基本储备（每人）

- [ ] **水**：56 升（每天 4 升）+ 过滤器 + 漂白水/净水片
- [ ] **食物**：14 天免烹饪或易烹饪食物 + 手动开罐器
- [ ] **照明**：LED 头灯 + 提灯 + 备用电池
- [ ] **电力**：充满电的充电宝 + 小型太阳能充电器
- [ ] **收音机**：手摇式调幅/调频/短波收音机
- [ ] **通信**：对讲机或 LoRa 网状网络设备；纸质联系人名单；家庭暗号
- [ ] **医疗**：急救包、止血带、个人药物、口服补液盐、备用眼镜
- [ ] **卫生**：桶、袋子、锯末/猫砂、肥皂、免洗洗手液、卫生巾等经期用品
- [ ] **保暖**：毯子、羊毛衣物、睡袋
- [ ] **钱**：小面额现金
- [ ] **纸质资料**：打印的指南、地图、证件复印件
- [ ] **安全**：一氧化碳报警器、二氧化碳检测仪、灭火器
- [ ] **医疗供电**：为制氧机、呼吸机等电动医疗设备准备 24–72 小时的电池后备
- [ ] **预先承诺**写在纸上：哪些消息或指令，全家在没有当面确认之前绝不相信、绝不照做（[第 6 章](06-information.md)）

## 📦 90 天 —— 深化

- [ ] 3 个月的轮换储粮（米、豆、燕麦、油、盐、蜂蜜、蛋白质罐头）
- [ ] 雨水收集，或能获取一个不依赖电网的水源
- [ ] 离网电力：0.5–2 kWh 磷酸铁锂 + 100–400 W 太阳能板，已关闭云功能
- [ ] 掩体空间已准备好（[第 2 章](02-low-cost-shelter.md)的第 0 级或第 1 级）
- [ ] 已完成急救 + 心肺复苏课程
- [ ] 已组建 3–5 户的小组；纸质技能地图
- [ ] 街区网状网络或无线电网每周测试
- [ ] 离线图书馆：Kiwix、离线地图、打印的手册——以及至少一本打印出来的官方防灾手册（[资源](resources.md)）
- [ ] 法拉第袋已测试（蜂窝网络、Wi-Fi 和蓝牙）
- [ ] 菜园已开垦；常规授粉种子储备

## 🌱 1 年 —— 韧性

- [ ] 第一次完整收获；从自己的作物中留种
- [ ] 练习过食物保存（晒干、发酵、罐装）
- [ ] 业余无线电执照（可选但很有价值）
- [ ] 野外急救或同等培训
- [ ] 合法建成地窖/覆土掩体（第 2 级），或已安装预制单元（第 3 级）
- [ ] 与亲友约定好乡下的后备地点
- [ ] 小组决策流程和冲突调解方式已商定
- [ ] 孩子的"模拟技能"课程：阅读、数学、地图、植物、工具
- [ ] 与至少一个其他社区团体建立联系

## 🎒 应急包（每人）

- [ ] 3 升水 + 过滤水瓶
- [ ] 3 天的食物
- [ ] 纸质地图、指南针
- [ ] 头灯、电池
- [ ] 急救包、药物
- [ ] 雨衣、保暖层、帽子、手套
- [ ] 刀/多功能工具、布基胶带、绳子
- [ ] 现金、证件复印件、联系人名单、暗号卡
- [ ] 手机用法拉第袋
